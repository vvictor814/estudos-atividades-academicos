#  Disciplina de Algoritmos, Lógicas e Programação

Repositório destinado aos estudos e atividades relacionados às aulas da disciplina de Algoritmos, Lógica e Programação, ministradas pela professora **Evelyn Karinne** no **PIT (Piauí Instituto de Tecnologia)**.

## Tecnologias utilizadas:
* Python
* Git e GitHub

## Conteúdos Estudados:
Aqui está um resumo dos tópicos abordados ao longo do semestre:
- [x] Conceitos básicos de algoritmos e fluxogramas
- [x] Variáveis e Tipos de dados
- [x] Estruturas condicionais (`se/senão`)
- [x] Estruturas de repetição (`enquanto/para`)
- [ ] Vetores e Matrizes (Arrays)
